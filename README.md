# 飞书多维表格 AI 自定义字段（增强版）

基于飞书多维表格 FaaS 的 AI 自定义字段插件。支持 7 种输出类型，兼容 30+ 家 OpenAI 格式 AI 服务商。

> 基于 [BlueSkyXN/Feishu-Bitable-Faas-AI-Filed](https://github.com/BlueSkyXN/Feishu-Bitable-Faas-AI-Filed) 重构增强。

## ✨ 特性

| 特性 | 说明 |
|------|------|
| **7 种输出类型** | 文本 / 数字 / 单选 / 多选 / 日期 / 对象（JSON） |
| **30+ 服务商** | OpenAI / Claude / Gemini / DeepSeek / 智谱 / 硅基流动 / 豆包 / Kimi 等 |
| **OneAPI 兼容** | 支持自建 OneAPI 网关，统一管理密钥和配额 |
| **结构化输出** | 每种类型都有专门的 System Prompt 指令和解析逻辑 |
| **字段引用** | 使用飞书自带的「⊕引用字段」按钮插入变量 |
| **MIT 协议** | 可自由商用，无 GPL 传染风险 |

## 🏗️ 架构

```
飞书多维表格 → AI 字段（FaaS）→ 调用大模型 API → 解析返回 → 写入单元格
```

- 代码运行在飞书 FaaS 服务端，API Key 不暴露前端
- 域名通过白名单管控（飞书平台强制限制）
- 无状态执行，每次调用独立

## 🚀 快速开始

### 环境要求

- Node.js >= 16
- npm 或 yarn

### 安装

```bash
npm install
```

### 开发调试

```bash
npm start    # 启动开发服务器
npm run dev  # 本地测试字段执行
```

### 构建打包

```bash
npm run build   # 构建
npm run pack    # 打包为 output/output.zip
```

打包完成后，在飞书开发者后台上传扩展包即可。

## ⚙️ 配置说明

创建 AI 字段时需要配置以下参数：

### 基础配置

| 参数 | 必填 | 说明 |
|------|------|------|
| 输出类型 | ✅ | 文本/数字/单选/多选/日期/对象 |
| 提示词 | ✅ | 点击「⊕引用字段」插入表格字段，然后描述 AI 任务 |
| 系统提示词 | ❌ | 设定 AI 角色 |

### 模型配置

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| API 地址 | ❌ | `https://api.siliconflow.cn/v1/chat/completions` | OpenAI 兼容接口地址 |
| API Key | ✅ | - | 服务商的 API 密钥 |
| 模型 ID | ❌ | `THUDM/glm-4-9b-chat` | 具体模型名称 |

### 参数配置

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| 温度 | ❌ | 1.0 | 0-2，越低越确定 |
| 最大 Token | ❌ | 无限制 | 限制输出长度 |

### 选项配置（单选/多选专用）

| 参数 | 必填 | 说明 |
|------|------|------|
| 候选项 | ❌ | 每行一个选项，AI 必须从列表中选择 |

## 📝 输出类型详解

### 文本（text）
自由文本输出。适用：总结、翻译、内容生成、文案写作。

### 数字（number）
返回数字。适用：评分、价格计算、统计数值、年龄提取。
> 自动从 AI 返回中提取第一个数字，兼容带单位/带文字的输出。

### 单选（single_select）
返回一个选项。适用：分类、情感分析、状态判断、打标签。
> 可配置候选项列表，AI 必须从列表中选。

### 多选（multi_select）
返回多个选项。适用：多标签分类、关键词提取、属性提取。
> 可配置候选项列表，AI 从中选一个或多个。

### 日期（datetime）
返回 ISO 格式日期时间。适用：日期提取、格式转换、到期日计算。
> 自动解析多种日期格式（YYYY-MM-DD、YYYY年MM月DD日等）。

### 对象（object）
返回 JSON 对象。适用：一次输出多个字段、结构化数据提取。
> 自动提取 ```json ... ``` 包裹的内容，解析失败则降级为 `{ raw: "..." }`。

## 💡 使用技巧

### 1. 如何引用表格字段

**使用飞书自带的「⊕引用字段」按钮**，不要手写 `{字段名}`。

操作步骤：
1. 点击提示词输入框
2. 点击「⊕引用字段」按钮
3. 选择要引用的字段
4. 字段名会以特殊格式插入，前端自动替换为当前行的值

> ⚠️ 提示：FaaS 字段后端收到的是已替换好的完整文本，所以不需要后端做模板替换。

### 2. OneAPI 对接

使用自建 OneAPI 网关时：

1. **API 地址**：填写你的 OneAPI 地址（如 `https://your-oneapi.com/v1/chat/completions`）
2. **API Key**：OneAPI 中生成的令牌
3. **模型 ID**：对应渠道的模型名称

好处：
- 统一管理多个模型渠道
- 每个令牌设独立额度和频率限制
- 完整调用日志和统计
- 自动故障转移

### 3. 单选/多选最佳实践

- 候选项尽量简洁，不超过 10 个
- 选项之间含义明确不重叠
- 系统提示词里补充判断标准
- 输出类型选单选/多选后，务必填写候选项

### 4. 对象类型使用示例

**场景**：从一段客户反馈中同时提取「情感倾向、问题分类、关键词、紧急程度」

提示词：
```
从以下客户反馈中提取信息：
{反馈内容字段}

输出包含以下字段的 JSON：
- sentiment: "positive" | "neutral" | "negative"
- category: 问题分类
- keywords: 关键词数组
- urgency: 1-5 数字
```

## 🔒 安全说明

- API Key 作为字段配置存储在飞书服务端，不会输出到前端
- 所有出站请求受域名白名单限制
- 建议使用 OneAPI 等网关统一管理密钥，方便轮换和撤销
- 字段配置仅表格管理员可见
