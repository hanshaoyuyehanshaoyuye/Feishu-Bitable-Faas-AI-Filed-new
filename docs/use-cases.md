# 应用场景示例

## 1. 客户反馈分析

| 字段 | 类型 | 说明 |
|------|------|------|
| 客户反馈 | 多行文本 | 原始数据 |
| 情感倾向 | AI单选 | 正面/中性/负面 |
| 问题分类 | AI单选 | 产品质量/物流/客服/价格/其他 |
| 关键词 | AI多选 | 自动打标签 |
| 紧急程度 | AI数字 | 1-5分 |

**单选候选项**（情感倾向）：
```
正面
中性
负面
```

**提示词**：
```
分析以下客户反馈的情感倾向，只返回一个词：
{客户反馈}
```

## 2. 简历筛选

| 字段 | 类型 | 说明 |
|------|------|------|
| 简历内容 | 多行文本 | OCR 或粘贴 |
| 学历 | AI单选 | 博士/硕士/本科/大专/其他 |
| 工作年限 | AI数字 | 年数 |
| 技能标签 | AI多选 | 匹配岗位关键词 |
| 匹配度评分 | AI数字 | 0-100 |

**提示词**（匹配度评分）：
```
根据以下简历，给岗位匹配度打分（0-100），只返回数字：
岗位要求：5年以上Java开发经验，熟悉Spring Boot，有微服务经验
简历：{简历内容}
```

## 3. 商品信息处理

| 字段 | 类型 | 说明 |
|------|------|------|
| 商品标题 | 文本 | 原始数据 |
| 品牌提取 | AI文本 | 从标题提取品牌 |
| 分类 | AI单选 | 一级分类 |
| 卖点提取 | AI多选 | 自动提取卖点标签 |
| 价格区间 | AI对象 | {min, max, currency} |

## 4. 日期提取

| 字段 | 类型 | 说明 |
|------|------|------|
| 文本内容 | 多行文本 | 含日期的自然语言 |
| 提取日期 | AI日期 | 自动识别并格式化 |

**提示词**：
```
从以下文本中提取提到的日期：
{文本内容}
```

## 5. 翻译 + 总结

| 字段 | 类型 | 说明 |
|------|------|------|
| 英文原文 | 多行文本 | - |
| 中文翻译 | AI文本 | 整段翻译 |
| 一句话总结 | AI文本 | 100字以内 |
| 关键词 | AI多选 | 核心概念 |

## 6. 数据清洗

| 字段 | 类型 | 说明 |
|------|------|------|
| 原始手机号 | 文本 | 格式混乱 |
| 标准手机号 | AI文本 | 统一为 138-xxxx-xxxx |
| 原始日期 | 文本 | 各种格式 |
| 标准日期 | AI日期 | ISO 格式 |

## 7. 内容分级审核

| 字段 | 类型 | 说明 |
|------|------|------|
| UGC 内容 | 多行文本 | 用户生成内容 |
| 风险等级 | AI单选 | 正常/低风险/中风险/高风险 |
| 违规类型 | AI多选 | 色情/暴力/广告/敏感词/其他 |
| 建议动作 | AI单选 | 通过/人工复审/删除 |
